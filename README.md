# Разработка прототипа системы поддержки принятия решений для онлайн-одобрения POS-кредитов на основе оптимизационной модели с портфельными ограничениями

Демонстрационный прототип оптимизационной модели онлайн-принятия решений
в POS-кредитовании с портфельными ограничениями (дневной лимит и доля высокорисковых кредитов).

## Технологии
* Python
* Streamlit (веб-интерфейс)
* Pandas, NumPy (обработка данных)
* Matplotlib (визуализация)


## Запуск:

python -m venv venv
.\venv\Scripts\activate

pip install -r requirements.txt

streamlit run app.py
