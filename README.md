[![tests](https://img.shields.io/badge/tests-14%20passed-brightgreen)](#тесты)
[![python](https://img.shields.io/badge/python-3.11-blue)](https://python.org)

Демонстрационный прототип оптимизационной модели онлайн-принятия решений
в POS-кредитовании с портфельными ограничениями (дневной лимит, доля
высокорисковых кредитов, резерв под крупные заявки).

## Постановка задачи

Банк получает поток POS-заявок в течение дня. По каждой заявке $i$
известны сумма $L_i$, вероятность дефолта $p^{d}_i$, вероятность
мошенничества $p^{f}_i$. Необходимо выбрать подмножество заявок для
одобрения так, чтобы:

1. максимизировать ожидаемую прибыль портфеля;
2. не превысить дневной лимит выдачи $C_{\max}$;
3. доля высокорисковых (крупных) кредитов не превышала $\theta_{\text{high}}$;
4. зарезервировать часть лимита под крупные заявки.

## Математическая модель

Введём бинарные переменные $x_i \in \{0, 1\}$ — решение по заявке $i$.

$$
\max_{x} \sum_{i} p_i x_i
$$

при ограничениях:

$$
\begin{aligned}
& \sum_i L_i x_i \le C_{\max} && \text{(дневной лимит)}\\
& \sum_{i: L_i \ge L_{\text{high}}} x_i \le \theta_{\text{high}} \sum_i x_i && \text{(доля высокорисковых)}\\
& \sum_{i: L_i < L_{\text{high}}} L_i x_i \le (1 - \text{reserve}) C_{\max} && \text{(резерв)}\\
& x_i = 0 \text{ для } p_i \le 0 && \text{(только прибыльные)}\\
& x_i \in \{0, 1\} && \text{(бинарность)}
\end{aligned}
$$

Ожидаемая прибыль по одному кредиту:

$$
p_i = (1 - p^{f}_i)\Big[L_i r \tfrac{T}{12}(1 - p^{d}_i) - p^{d}_i L_i (1-\gamma)\Big] - p^{f}_i(L_i + C_{\text{op}})
$$

**Реализация:** LP-релаксация — `scipy.optimize.linprog` (HiGHS);
целочисленное решение — `pulp` + CBC.

## Стратегии

| Стратегия | Логика | Назначение |
|---|---|---|
| **Жадный** | одобряем всё, что с положительной ожидаемой прибылью | baseline |
| **Скоринговый порог** | $p^d < 0.15$, $p^f < 0.05$, $p > 0$ | классический скоринг |
| **Скоринг + Лимит** | скоринг + $C_{\max}$ | скоринг с учётом ликвидности |
| **Предложенный** | скоринг + $C_{\max}$ + резерв + доля риска | эвристика из ВКР |
| **MILP (оптимум)** | точное решение | эталон для сравнения |
